PROJECT STATEMENT 


## Problem Statement
I sometimes forget about the small things I have to do each day since I never write them down in an organised manner. That's why I decided to create a simple tool which would allow me to add my tasks quickly, see them all in one place, and tick them off once they're completed — all without having to use a phone app or paper notes.

## Scope
It is a simple command-line (terminal) project developed with Python; it includes neither a graphical user interface nor any connection to the internet, unlike the case with the tasks which are saved in a text file on the computer and so are still there when I next run the program.

What it can do:
- Add a task
- See all my tasks
- Mark a task as done
- Delete a task
- See a quick summary (how many tasks are done/pending)

What it does NOT do (not in scope for this project):
- No login/accounts for multiple users
- No due dates or reminders
- No internet/cloud saving

## Target Users
The project has been created primarily for myself since I'm a student, or for anyone else who wants a simple method of keeping track of their daily to-do items without having to install any additional software.

## High-Level Features
- Add a task with a priority (High / Medium / Low)
- View tasks, sorted so important ones show first
- Mark tasks as complete
- Delete tasks I don't need anymore
- Check a summary of how many tasks are pending vs completed
- Saves data automatically to a file so nothing is lost when I close the program
